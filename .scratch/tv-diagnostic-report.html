This isn't a broken playlist — Internet Archive is having an outage

82% of the catalog is failing, but the pattern gives it away: archive.org's homepage and metadata API both respond normally (200), and every file is still listed in its item's metadata. It's specifically the file-serving layer that's down. Sixty of the failures come straight from Internet Archive's own backend, which returns a page titled "Internet Archive: Error" with the trace download.php:1059:exit_service_unavailable — that's their code, not a network issue on this end. Another 35 come from individual storage nodes (e.g. dn711504.ca.archive.org) throwing 500s while that same item's metadata confirms the file is still there.

Retried every failure three times, several minutes apart, with redirects followed — the failures held steady, so this isn't a one-off blip from the check itself.

→ Action for the playlist: none needed. These URLs should start working again once Internet Archive's outage clears — nothing here points to files being deleted or the JSON being wrong.
